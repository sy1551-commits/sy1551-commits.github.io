Privacy Policy

Slow Pour Uploader · Effective October 5, 2026

Slow Pour Uploader is a private tool used only by the operator of the Slow Pour YouTube channel to manage that channel's own videos. It is not offered to the public, and no other person's account is ever connected to it.

What the tool accesses

With the channel owner's permission (Google OAuth, YouTube Data API scope youtube.force-ssl), the tool:

  • uploads videos to the Slow Pour channel as private drafts;
  • reads and updates the titles, descriptions, tags and thumbnails of the channel's own videos;
  • posts and edits the channel's own comment (such as a pinned tracklist) on its own videos. To find that comment it lists comments on the channel's own videos; other people's comments are not stored or used for anything else.

It does not access subscriber lists, viewer information, email, contacts or any other Google data.

How data is stored

The OAuth token is stored only on the operator's own computer. No data from Google APIs is sent to any server run by Slow Pour or to any third party, and nothing is sold, shared, or used for advertising.

Google API Services User Data Policy

Slow Pour Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local token file also ends the tool's access.

Contact

Questions about this policy can be sent through the contact details on the Slow Pour YouTube channel.
